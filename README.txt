QQBot-Pack —— QQ 机器人一键封装包（绿色目录版）
========================================================

这是一个"绿色目录包"：拿到它，装好 Node.js，按下面 5 步走，就能在自己电脑上
跑起一个属于你的 QQ 群聊 AI 机器人（NapCat 登录你的 QQ 小号 + DeepSeek Harness
AI + 桥接 + 本地管理台）。整个包就是一个文件夹，拷到别的电脑也能用。

--------------------------------------------------------
【⚠️ 前置要求 —— 先看完再动手】
--------------------------------------------------------
 1. Windows 10 / 11（64 位）。
 2. Node.js 22 或更高版本（含 npm）。没有的话先到 https://nodejs.org 下载安装
    （一路"下一步"即可，装完可能要重启一次终端/资源管理器）。
    检查方法：按 Win+R 输入 cmd 回车，在里面敲  node -v  ，能显示 v22.x 或更高即可。
 3. 一个【你自己的 QQ 小号】（强烈不建议用常用大号：机器人行为 + 登录风控有
    可能影响账号，用专门小号最安全。小号需要能被拉进你的群）。
 4. 一个 DeepSeek API Key（到 https://platform.deepseek.com 注册后在"API Keys"
    里创建，形如 sk-xxxxxxxxxxxx）。这个 Key 只填在你自己的电脑上，不需要发给任何人。
 5. 首次安装 DSH 需要联网（会从 npm 下载组件，国内已自动走镜像加速）。
    之后的日常运行不需要额外联网（AI 对话除外——AI 回复走 DeepSeek 官方接口）。
 6. 【换机风控提醒】换一台新电脑/新设备登录 QQ，腾讯一定会要求验证：扫码或
     短信验证码。这是腾讯的正常风控，不是故障，照引导做即可（详见
     docs\操作文档.txt 第四节"登录引导"）。

--------------------------------------------------------
【5 步快速开始】
--------------------------------------------------------
 第 1 步：双击  首次配置.bat
          · 自动检查 Node.js；
          · 自动生成 config\bridge.config.json（从模板复制）；
          · 自动把 DSH（DeepSeek Harness）安装到 app\dsh（首次较久，耐心等）。
 第 2 步：用记事本打开 config\bridge.config.json，照着里面的中文说明填写：
          · groups（群白名单：机器人只在列出的群里说话）；
          · owner（主人：你的 QQ 号和昵称，可选）；
          · bot.name（机器人名字，可选）；
          · 人设档案 persona\我的机器人.txt 改成你自己的设定（可选但推荐）。
 第 3 步：双击  启动全部.bat
          启动器会自动依次拉起 NapCat、DSH、管理台，然后尝试打开管理台网页。
          （各服务窗口请保留别关，关了对应服务就停。）
 第 4 步：按提示完成两件"一次性"的事（都不难）：
          A. 登录 QQ 小号：浏览器打开 http://127.0.0.1:6099/webui （管理台上也有
             一键打开按钮），用手机 QQ 扫码登录你的小号。首次/换机要求验证码
             或短信验证，属正常。
          B. 填 API Key：浏览器打开 http://127.0.0.1:3080 （DSH 控制台），在设置里
             填入你的 DeepSeek API Key，并选一个可用的模型（如 deepseek-chat）。
 第 5 步：回到管理台 http://127.0.0.1:3210 刷新状态，等 NapCat / DSH / OneBot /
          桥接四张卡片都变绿（OneBot 要等小号登录后才绿）。然后把你的 QQ 小号
          拉进群、@ 它说话，机器人就上线啦！

--------------------------------------------------------
【端口一览】（都是本机 127.0.0.1，不对外网开放）
--------------------------------------------------------
  6099  NapCat 网页版（扫码登录小号 / NapCat 管理）
  3001  OneBot WebSocket（NapCat → 桥接的消息通道）
  3080  DSH 控制台（填 API Key、看 AI 会话）
  3210  QQBot 管理台（本包门户 + 管理面板，日常主要用它）
  34567 桥接单实例锁（防止重复回复，一般不用管）

--------------------------------------------------------
【日常操作】
--------------------------------------------------------
  启动全部服务 ...... 启动全部.bat
  只启动桥接 ......... 启动桥接.bat（比如 NapCat 掉线重登后手动补拉桥接）
  停止全部服务 ....... 停止全部.bat
  修改白名单/规则 .... 管理台 http://127.0.0.1:3210 → 管理面板（热生效，不用重启）
  查看日志 ........... 管理台 → 管理面板 → 日志查看
  详细文档 ........... docs\操作文档.txt（配置字段、登录引导、故障排查全在里面）

--------------------------------------------------------
【安全提醒】
--------------------------------------------------------
  · 本包所有服务只监听 127.0.0.1（仅本机），不会对局域网/公网开放。
  · API Key、QQ 号等敏感信息只存在于你自己这台电脑的 config 和 app\dsh\home 里。
  · 要把这个包分享给别人时，先删掉 config\bridge.config.json（你自己的群号/Key
    配置）再打包——让对方自己跑首次配置。
  · 用 QQ 小号 + 遵守腾讯规则，风控/封号风险自负（详细见 docs\操作文档.txt）。
